# Digital Assets Trading Platform  

**Built at the ITMarathon Hackathon 2024 in Iași**  

---

## About the Project  

A classmate and I developed the **backend** for a digital assets trading platform during the ITMarathon Hackathon 2024.  

### Platform Features  
The platform allows users to:  
1. **Track asset prices** in real-time.  
2. **View their owned assets** and portfolio details.  
3. **Buy or sell assets** seamlessly through an intuitive interface.  

---

## Technologies Used  

- **ASP.NET Framework**: For building a robust and scalable backend.  
- **Dapper**: For lightweight and efficient data mapping between the application and the database.  

---

## Contributions  

- Designed and implemented APIs to handle core platform functionalities, such as:  
  - Asset tracking.  
  - Portfolio management.  
  - Transaction handling for buying and selling assets.  
- Ensured smooth data mapping and efficient database interactions with Dapper.
